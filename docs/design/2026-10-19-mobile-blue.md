# EDU톡 모바일 디자인 반영

원본 Claude Design: https://claude.ai/artifact/156pbwyKCF22Qz7iyUtXXa

사용자 확정: 모바일 중심, 기존 토스 블루 유지, VPS의 edutalk.ai-hub-os.com으로 배포.

- 기존 DESIGN.md 색상 유지: #3182F6 / #1B64DA / #E8F3FF, 배경 #F7F8FA.
- 홈: 두 경로 선택, 교육자 일터 기본 선택, 검색과 지역 아래 관련 기관을 우선 표시.
- 기관 카드: 학생·학부모·교육자 평가를 분리하고 교육자 근무후기 공개 기준을 일관되게 적용.
- 검색: 모바일 2열 조건 폼과 큰 입력, 목록의 중첩 카드 배경 정리.
- 상세: 기관명·신뢰 정보의 위계와 52px 연락 버튼. 기존 데이터·연결 동작 유지.
- 공통: 13px 메타 글자, 기본 44px 이상 터치 영역, 기존 역할별 하단 메뉴 유지.

Claude의 정적 HTML을 앱 대신 배포하지 않고 Next.js의 실제 데이터·상태·라우팅에 디자인을 이식했다. 체험 데이터와 계정 데이터 경계 및 기존 개인 기능을 유지한다.
