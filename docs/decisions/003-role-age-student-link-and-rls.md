# ADR 003: 역할·연령·학생 연결과 권한 모델

- 날짜: 2026-08-13
- 상태: Accepted for implementation

## 배경

학생 성적·성장 기록, AI 초안, 학부모-교사 메시지는 역할과 학생 연결에 따라 보이는 범위가 달라야 한다. 화면에서만 역할을 바꾸는 방식으로는 이 경계를 지킬 수 없다.

## 결정

- 역할은 계정의 DB 역할로 관리하고, 온보딩에서 연령·동의·대표 역할·최소 프로필을 기록한다.
- 만 14세 미만은 보호자 아래 자녀 프로필로 처리하고 독립 학생 역할 선택을 제한한다.
- 교사가 학생을 등록하고, 학생·보호자·담당 교사의 활성 연결을 기준으로 기록과 대화방 접근 범위를 정한다.
- 데이터베이스의 행 단위 권한 규칙으로 본인·보호자·담당 교사·승인된 운영자만 필요한 데이터를 읽거나 바꾸게 한다.

## 결과

- 학생별 성적, 성장 기록, AI 일지·생기부, 메시지와 첨부는 개인 기능으로 남는다.
- AI 일지 공유는 교사 확인 뒤에만 진행한다.
- demo 모드의 역할 전환과 브라우저 저장 상태는 실제 계정 권한이나 동의 기록이 아니다.

## 외부 미연결 항목

실제 Supabase 프로젝트·마이그레이션 적용, Auth 연결, 실제 운영 역할 배정, 법률 검토가 아직 완료되지 않았다.
