# ADR 004: 후기 인증·공개 기준·비공개 증빙 경계

- 날짜: 2026-08-13
- 상태: Accepted for implementation

## 배경

후기는 기관·일터·튜터 선택에 영향을 준다. 동시에 작성자 보호, 근무 관계 익명성, 증빙 원본 보호와 신고·정정 처리가 필요하다.

## 결정

- 기관 후기는 이용·근무 관계 인증과 승인 절차를 거쳐 처리한다.
- 학부모·학생·교육자 점수는 서로 섞지 않는다. 교육자 일터 공개 점수는 승인된 교사 후기 3건 이상일 때만 표시한다.
- 광고·유료 노출은 기관·일터·튜터 순위에 가중하지 않는다.
- 기관 관계자 답변은 승인된 공개 후기의 별도 답변으로 처리하며, 작성자 신원은 공개하지 않는다.
- 증빙 원본은 비공개 Storage와 최소 메타데이터로 다루고, 운영자 원본 확인 링크는 짧은 시간만 유효하게 한다.
- 작성자는 후기를 내릴 수 있고, 열람자는 특정 후기를 자신의 계정에서만 숨길 수 있다. 공개 집계·랭킹·공식 답변에서는 작성자가 내린 후기를 제외한다.

## 결과

- 공개 화면에는 검증 상태와 필요한 최소 정보만 표시한다.
- 개인정보·식별 위험 신고는 먼저 임시숨김으로 처리한 뒤 검토·복원·종료 상태를 남긴다.
- 증빙 파일, 작성자 신원, 신고자 정보는 공개 후기나 운영 로그에 포함하지 않는다.

## 외부 미연결 항목

실제 Storage 버킷·운영자 계정·심사 인력·보관 삭제 기준·법률 검토·실데이터 운영은 아직 연결 또는 확정되지 않았다.
