# ADR 002: Canonical 기관 ETL과 합성 데이터 분리

- 날짜: 2026-08-13
- 상태: Accepted for implementation

## 배경

기관 탐색·비교·랭킹 화면은 초기에는 체험 데이터를 사용한다. 이를 실제 동탄 기관 정보처럼 보이게 하면 이용자 판단과 운영 데이터가 혼동될 수 있다.

## 결정

- 실제 기관은 공공 데이터 형식을 정규화한 canonical 기관 테이블에만 적재한다.
- 동탄1·동탄2 등 서비스 구역은 canonical 기관의 공개 정보와 함께 관리한다.
- 합성 체험 데이터는 `is_synthetic` 경계로 구분하고 production 공개 데이터·계정 비교·순위에 섞지 않는다.
- 동기화는 먼저 dry-run으로 형식·중복·기준일을 확인한다. 실제 write는 승인된 운영 절차에서만 한다.

## 결과

- 계정 모드의 공개 기관 비교·관심·랭킹은 canonical 공개 slug를 기준으로 다룬다.
- demo 모드는 기존 브라우저 체험 데이터를 유지하되 실제 데이터가 아님을 표시한다.
- 기관명·주소·출처·기준일을 보존해 나중에 변경 근거를 확인할 수 있다.

## 외부 미연결 항목

실제 공공 API 승인·계약·키, 운영 데이터 적재, 동기화 작업, 실제 동탄 기관 기준 데이터는 아직 연결되지 않았다.
