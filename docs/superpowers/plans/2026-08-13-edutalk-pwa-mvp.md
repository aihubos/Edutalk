# EDU톡 PWA MVP Implementation Plan

> **For agentic workers:** 구현은 아래 순서대로 진행하고 체크박스로 추적한다. 이 프로젝트에서는 기능 구현을 우선하며, 멀티에이전트 리뷰와 테스트, 보안, 해시 작업은 하지 않는다.

**Goal:** 현재 구현된 `demo` 흐름을 기준으로, 아이·학부모의 배움 탐색과 교육자의 일터 탐색을 분리하고 학생 관리·튜터·소통을 확인할 수 있는 모바일 우선 PWA MVP를 만든다. 이 문서는 상용 출시 완료를 뜻하지 않는다.

**Architecture:** Next.js App Router 단일 앱으로 시작한다. 현재는 체험용 로컬 저장소와 fixture를 사용하며, Supabase SSR 계정 기반, canonical 기관 DB, 서버 AI 사용량 함수를 연결할 자리를 준비한다. 실제 외부 연결과 운영 처리는 아직 하지 않았다.

**Tech Stack:** Next.js 16, React 19, TypeScript, CSS, Lucide React, OpenAI Responses API, localStorage, Supabase 마이그레이션 기반

---

## 파일 구조

- `app/`: 화면과 라우트
- `components/`: 공통 앱 셸, 탐색, 상세, 후기 컴포넌트
- `lib/`: 데이터 타입, 체험 데이터, 역할 규칙, 저장소
- `public/`: PWA manifest 자산과 서비스 워커
- `docs/`: 설계, 연결 방법, 운영 준비 항목

## 상용 공개 전 차단 조건

- [ ] Supabase 프로젝트 연결과 현재 마이그레이션 적용: 학습·튜터·자격 증빙·기관 후기·소통 스키마가 준비돼 있지만 아직 적용되지 않았다.
- [ ] 실제 로그인, 저장소, 결제 웹훅, 공공기관 데이터, canonical DB 적재, 운영자 심사를 연결한다.
- [ ] 연령 확인·보호자 동의·학생 역할 제한을 실제 계정·서버 권한에도 적용하고 정식 약관·개인정보처리방침을 연결한다.
- [ ] 교육자 일터 후기는 실제 이용 관계 확인, 공개 익명화, 확인 후기 3건 이상 조건을 서버에서 강제한다.
- [ ] 학생·학부모·교육자 점수 분리, 광고 없는 순위 산식, 외부 후기 원문 링크 전용 원칙을 서버·운영 정책에도 적용한다.
- [ ] 튜터 신원·자격 증빙의 비공개 보관·심사·삭제 정책과 학생 소통의 권한·첨부파일 정책을 확정한다.
- [ ] 후기·명예훼손, 학생 개인정보, 아동 보호, 결제·전자상거래 관련 검토와 비공개 베타를 마친다.
- [ ] 실제 탈퇴 요청 접수·본인 확인·계정 및 데이터 처리·고객센터 운영 절차를 연결한다.
